# 72 Hours Before Landfall

*Turning hurricane data into decisions for Puerto Rico.* A tabletop exercise run on one projected map: a hurricane
approaches, each round is one of the National Hurricane Center's real advisories, and tables of emergency managers,
health, housing and utility staff decide where to act first, say why, and revisit as the forecast changes. The
storm's name stays hidden until the end, when its actual track and what it did are laid over the decisions.

**[Open it → webgpu-demos.github.io/landfall](https://webgpu-demos.github.io/landfall/)**

Built from public data, with the lessons and the baked data of [Garita](https://github.com/webgpu-demos/garita).
An independent demonstrator, not for operational use.
